# Lessons

## 2026-07-20 旧仓库冲突先对齐迁移目标

- **Trigger:** 旧格式仓库占用了新格式固定路径，用户是在配置或初始化时遇到冲突。
- **Rule:** 先确认用户是否要保留并转换旧备份；若迁移实现禁止源目标重叠，应把新仓库说明为转换的临时/复制目标，并优先给出可逆的“重命名旧仓库 → 初始化新仓库 → 迁移 → 验证”流程，不要表述成放弃旧备份另起炉灶。
- **Why:** 避免把安全迁移所需的独立源目标误解成用户需要新建一套无关备份。

## 2026-06-28 TypeScript CLI SOP 泛化

- **Trigger:** 用户要求创建通用 SOP、流程文档或跨项目规则，并提供某个项目作为参考。
- **Rule:** 只抽取通用流程和检查点；不要把参考项目名称、工具版本或私有约定写成默认规则。可以推荐生态常见库，但要表述为新项目/无既定选择时的通用建议。
- **Why:** 防止可复用 SOP 退化成单个项目的实现清单，同时保留对新项目有用的默认库建议。
